Privacy policy

Vrishn keeps tab data on your device.

Vrishn - Quick Tab Switcher is a browser extension for searching, cycling through, and switching between open tabs. This policy explains what data the extension uses and how it is handled.

Effective date: June 1, 2026

Data The Extension Uses

Vrishn uses open tab metadata, including tab titles, URLs, favicons, pinned status, window IDs, and active tab state. This lets the extension show searchable tab results, keep recently used tabs in order, and switch to the selected tab.

Vrishn also stores extension preferences such as popup size, accent color, current-window-only mode, pinned-tab visibility, search restore preference, and recent-tab ordering.

How Data Is Stored

Tab order and preferences are stored locally with browser extension storage on the user's device. Vrishn does not send this information to any server.

What The Extension Does Not Collect

Vrishn does not collect personally identifiable information, health information, financial information, authentication information, personal communications, location data, website content, or user activity unrelated to its single purpose as a tab switcher.

Vrishn does not use analytics, ads, tracking scripts, or remote code.

Sharing And Sale Of Data

Vrishn does not sell, rent, transfer, or share user data with third parties. Data used by the extension is only used for tab switching, search, and user-selected settings.

Permissions

The extension requests tab access so it can read the titles and URLs of open tabs and switch to the selected tab. It uses local storage so settings and recent-tab order continue to work after the browser restarts.

Contact

For privacy questions or support, open an issue on the Vrishn GitHub repository.
